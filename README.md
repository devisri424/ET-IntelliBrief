# ET IntelliBrief 

ET IntelliBrief is an AI-powered business news platform that helps users understand complex news through AI-generated summaries and explanations.

## Features

* AI Deep Briefing
* Tamil & Hindi Explainer
* Ask ET AI (news chatbot)
* Persona-based insights
* Business news aggregation

## Tech Stack

* React.js
* FastAPI
* Google Gemini API
* News API

## Setup

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend/newsapp
npm install
npm run dev
```
